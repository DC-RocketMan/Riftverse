# Mikrokosmos-Zelle

<BlockImage id="mikrokosmos_zelle" scale="2" float="right" />

Eine Autobatterie mit Glasdeckel, darunter eine winzige Stadt. Die Bewohner erzeugen deinen Strom – **2.000 bis
8.000 FE/t auf Stufe III**. Sie wissen nicht ganz, wofür.

<br clear="all" />

- **Nahrung:** Alle 10 Sekunden essen sie so viel, wie ihre Stufe hoch ist.
- **Material:** Alle 20 Sekunden verbauen sie etwas (Barren, Platten, Bretter, Ziegel, Glas).
- **Zufriedenheit:** Bei 90 % steigt die Zivilisation eine Stufe (bis 4 = 8.000 FE/t). Bei 0 % wird gestreikt.
- **Abzug:** Ein Knopf regelt, wie viel Strom du abzweigst (25–100 %). Viel Abzug macht unzufrieden.

Gut versorgte Bewohner sind die stärkste Quelle vor der letzten Stufe. Schlecht versorgte bringen gar nichts.

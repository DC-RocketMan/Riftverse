# Bauteile

Wie bei den Schaltkreisen von Mekanism gibt es in Riftverse **Leitern**: Jede Stufe eines Bauteils braucht die vorige.
Wer eine Quanten-Schaltung will, braucht also erst einen Rift-Schaltkreis, und der braucht einen Basis-Schaltkreis.

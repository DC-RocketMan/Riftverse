# Gadgets und Rüstung

Erfindungen für unterwegs und eine Rüstung, die so schwer zu bauen ist, dass sie das längste Projekt im ganzen Pack
wird.

- **Gadgets** laufen fast alle mit FE aus einem eigenen Akku. Sie laden in jedem Ladegerät und im Akku-Slot jedes
  Generators. Siehe [Gadgets](gadgets.md).
- Das **Multiversal-Multitool** ist Bohrer, Schraubenschlüssel und Scanner in einem. Siehe [Multitool](multitool.md).
- Die **Multiversal-Rüstung** hat keine Haltbarkeit, sondern läuft mit FE, hat Modul-Slots und drei Ausbaustufen.
  Siehe [Rüstung](ruestung.md) und [Module](module.md).

# Biomasse-Kessel

<BlockImage id="biomasse_kessel" scale="2" float="right" />

Ein Kupferkessel mit Bullauge, in dem etwas pulsiert. **80 FE/t auf Stufe I** aus Pflanzen oder Biomasse-Pulpe.

- **Pflanzen** (Setzlinge, Weizen, Laub …) brennen kurz.
- **Biomasse-Pulpe** aus der organischen Welt brennt viermal so lange und gibt als Nebenprodukt Nährserum für den
  Klon-Tank.

Eine Baumfarm oder ein Kürbisfeld reicht für den Anfang – richtig gut wird der Kessel mit Pulpe.
